# 04 前端与精简实施约定

依据：../WEB-DEVELOPMENT-PREFERENCES.md（相对本项目根目录），以及现有 text-vault-go 的 Go embed / VanJS / 薄 fetch API 风格。项目目录直接位于 arch-webdev/site-panel，与现有各项目并列；不搬动其他目录。

## 为什么这套风格够用

本产品是节点和站点表格、设置表单、文件目录、配置编辑和任务结果。不需要 SSR、SEO、复杂多人协作或大型前端状态框架。30～50 台服务器和约 150 个站点本身不会要求 Vue/React。

VanJS 负责页面状态和真实 DOM，原生 CSS 负责样式，Go API 负责真实校验和执行。采用小技术不意味着所有专业能力都要自写。

## 固定选型

- VanJS：函数组件、van.state，普通 JS 模块。
- 原生 CSS：使用 styles.css，按实际需要拆分样式文件；使用普通 class 和 CSS 变量，不引入 goober、CSS-in-JS 或 CSS 预处理器。用户说明 goober 仅为其手写时方便，不是本项目依赖。
- fetch：api.nodes()、api.install()、api.deploy()、api.taskLogs() 等薄封装。
- Go net/http + SQLite，前端与 API 同源。
- 本地 vendor 固定版本、记录来源和许可证，不依赖 CDN。Lucide 1.60.0 只引入实际用到的 ESM 图标和 SVG 创建函数。
- 无 JSX、TypeScript、Vite、全局状态框架、RPC 框架或通用 CRUD 引擎。

## 已实现的工作区布局

- 左侧 IP + 备注；右上是当前节点的站点、域名、SSL 剩余天数、Nginx、文件、部署、日志列表。
- 右下是实际操作区：文件树 + 多标签 Ace、只读 Nginx、SSL，或者任务表 + 日志输出。域名/HTTP 端口由站点行“编辑”保存到主控，部署后生效，不再单独放重复的信息页。
- 参照最新扁平 MD / Win8 参考图：白色操作区、少量纯色色块、细分隔线、Lucide 图标，所有按钮方形。禁止横幅、统计卡片、圆角阴影、渐变、英文装饰标题和人为大留白。
- 底部仅一行紧凑状态栏，显示实际操作结果和当前节点任务入口；删除可折叠/可调整高度的日志抽屉。站点行“日志”、底部入口均直接打开日志；任务名称可直接点击切换输出，支持刷新、复制、下载。
- `GET /api/tasks?node_id=...` 在 SQL 过滤后才取最近 50 条，不是先截取全部节点再在浏览器过滤。轮询也只查询当前节点；日志与刷新请求携带 node_id，后端拒绝与任务不符的上下文。切换节点立即清空任务/旧日志、取消日志请求，迟到的列表和日志响应不能写回。
- 在操作区切换任务/编辑视图只隐藏 DOM，不销毁编辑器或草稿。切到其他节点仍需遵守未保存确认。
- 保留明确的“保存到主控”和“同步到节点”；有草稿时禁止直接同步。切换站点、关闭文件需确认放弃；切换 Nginx/文件页不丢草稿。
- 任务轮询、刷新列表只更新各自 DOM，不重建 Ace。离开工作区销毁实例和监听器；登录过期使用重登录弹窗保留编辑内容。
- 窄屏保持同一矩形布局，列表内横向滚动；不引入 UI 框架、路由框架或分栏库，使用原生 Grid/Flex、Pointer Events 和普通函数。

## UI 范围

- 节点表格、站点表格、文件列表：先使用原生 table 与少量函数组件，筛选/分页按实际数据量实现；不急着引入复杂表格库。
- 表单：原生 input/select/textarea，统一错误提示、确认和提交状态。
- 弹窗：原生 dialog，处理焦点、Esc、未保存内容确认；不靠浏览器 alert 堆界面。
- 配置/文本编辑：采用 Ace 1.45.0 的本地浏览器发行文件，按需加载核心与所需语言模式，保留 1 MB 文本编辑限制。提供行号、高亮、查找替换、撤销重做、Ctrl+S 和未保存提醒。使用官方外部 CSS 与 strict CSP，不放开 unsafe-inline/unsafe-eval；关闭 worker，不把高亮当成校验。
- 任务进度：先轮询任务结果，不上 WebSocket 状态总线。页面离开清理定时器，重进可按任务 ID 查询。
- 文件上传：大文件发送 File/Blob 或 multipart，不转成 base64，不把 APK 塞进 JS 响应式状态。需要真实上传进度时使用浏览器支持的上传进度 API，不能把开始请求就显示为完成。
- 错误内容用文本 DOM 输出，不把服务端错误、文件名或 Nginx 内容拼进 innerHTML。

专业库只管理自己挂载的 DOM 子树，VanJS 不反复重建该子树；销毁时清理实例与事件。不要因为无构建偏好而重写代码编辑器、SSH、ACME 或密码算法。

## 最小目录示意

```text
cmd/panel/          主控入口
cmd/node/           按任务运行的节点执行器入口
internal/panel/    HTTP 接口、主控操作与 SSH/SFTP 调用
internal/node/     固定任务执行和 JSON 状态查询
internal/panel/store.go  SQLite 和具体 SQL
web/
  index.html
  styles.css
  vendor/
  js/
    app.js         登录、IP 列表、站点表、任务日志装配
    api.js         fetch 与统一错误处理
    editor.js      Ace 的薄适配、语言选择和生命周期清理
    workspace.js   站点操作区、文件标签和编辑器生命周期
    ssl.js         SSL 表单、公开证书状态、剩余天数
    files.js       无 DOM 的文件树、大小和状态名称工具
    ui.js          按钮、原生弹窗、图标和可访问分栏手柄
```

以上按实际功能拆分，不提前创建空目录和十几层 service/repository/interface。共享类型在真实需要时抽取；文件变大或重复出现后再拆分。

## 必要复杂度与多余抽象

保留：数据库事务、认证、路径校验、任务 ID、结果落盘、节点串行、候选配置检查。这些直接对应可复现的故障，不是框架装饰。

暂不做：常驻 Agent、通用节点插件、任务 DAG、事件溯源、依赖注入容器、万能表单/表格配置语言、完整状态同步引擎、跨项目组件平台。

顺序：先写能看见结果的具体流程，再提取重复代码。设计文档是边界与验收说明，不要求把每个名词实现成一层抽象。
