# 03 开发阶段与验收

路线固定为 SSH/SFTP 直推、小型 Go 执行器、systemd 按任务运行、SSH 查询结果；不再先做常驻 Agent。首个静态部署闭环现已完成；本文保留分阶段验收目标，并非所有条目均已实现，具体测试记录见 [当前实现](05-status.md)。

## 阶段 0：最小骨架

- 检查 Go 工具链，初始化本项目 module，不创建 Vue/Vite 项目。
- Go net/http + SQLite，VanJS/原生 CSS 同源静态资源。
- 首次账号设置、单会话、主控加密密钥和数据库迁移。
- 本地主控仅回环监听，不要求 Tailscale、公网地址或节点回连。

验收：本地能启动、登录、重启保留数据；无默认通用密码、无明文 SSH 密码落库。

## 阶段 1：SSH 节点与执行器

- 节点列表、连接资料、指纹确认、只读环境检查。
- SSH/SFTP 安装固定执行器与 systemd 模板，查询 JSON 状态。
- 持久化任务 ID、提交、运行、结果查询、断线后查询；节点串行。

验收：

- [ ] 在面板添加测试服务器并完成安装，不手工复制绑定码。
- [ ] 口令错误、指纹变化、超时、系统不支持有明确错误。
- [ ] 重复安装不破坏已有受管内容；冲突业务停止并提示。
- [ ] 任务独立于 SSH 执行，断开连接后可重连查询。
- [ ] 提交响应丢失后用同一 ID 重试，不启动重复任务。
- [ ] 服务器重启后未完成任务显示待核实，不误报成功。
- [ ] 移除节点不删远端业务，再添加不清空或自动覆盖站点。

远端目前仅做过只读检查；安装前需复检并说明实际改动。

## 阶段 2：一个真实静态站（最优先）

- 站点列表、完整 Nginx 站点配置编辑，域名/端口从配置识别。
- 主控文件上传、列表、文本编辑。
- 文件准备/校验/切换、Nginx 检查/reload、结果显示。

验收：

- [ ] 无需用户手动 SSH，在面板上传 index.html 并通过 IP:端口访问。
- [ ] 修改内容再同步可以访问新内容。
- [ ] 两个域名共享 80 端口正确分流。
- [ ] Vue history 路由与 /api/ 代理按配置工作。
- [ ] 主控已保存但未应用与线上成功可明确区分。
- [ ] 错误配置、上传中断、磁盘不足不破坏旧站。
- [ ] 重复操作串行，关闭浏览器/主控不停止已启动任务和网站。
- [ ] SSH 不可达显示未知及采集时间，而非 Nginx 停止。

完成此阶段即可演示部署核心，SSL 不阻塞它。

## 阶段 3：文件管理与可靠性补齐

新建、下载、重命名、删除、ZIP、差异/删除确认、大文件与临时目录清理。

- [ ] APK 完整上传下载，不用 base64/整体内存缓冲。
- [ ] 主控编辑锁防止同步混入未确认修改。
- [ ] 删除预览后确认，空目录/删除主控文件有明确语义。
- [ ] 路径穿越、符号链接、超大压缩展开被拒绝。
- [ ] 每个关键阶段重启后可恢复或明确转人工核实。
- [ ] 清理不删当前运行目录、活跃任务、其他站点。

## 阶段 4：SSL

成熟 ACME 工具、HTTP-01、证书上传、独立续期、主控主动取回。

- [ ] 先测试 CA 环境，最终使用测试域名签发。
- [ ] DNS/80 端口/CAA/CA 错误原因明确，旧站保留。
- [ ] 证书/私钥匹配、域名覆盖、有效期检查。
- [ ] 主控离线续期正常，重连采集最新证书。
- [ ] 旧副本不覆盖节点新证书；界面显示最后采集时间。

## 阶段 5：恢复演练与小范围试用

- [ ] 原节点不可访问，从主控恢复到另一台空白节点。
- [ ] 指定 Host/SNI 访问新 IP 验证后再手动切 DNS。
- [ ] 同域名恢复有效证书，换域名提示新证书要求。
- [ ] 失败不提前解除原节点绑定，不自动删旧节点内容。
- [ ] 主控备份在独立实例恢复，包含解密密钥、文件与证书。

## 测试重点

单元测试：路径、配置约束、SSH 指纹、加解密、状态和重复提交。

集成测试：SQLite、SFTP、systemd 执行与 Nginx 真检查。

故障测试：断网、丢响应、重复提交、节点重启、磁盘不足、半文件、安装中断、错误配置、结果文件缺失。

公网测试：DNS、云防火墙、证书和真实代理；本地通过不代表公网成功。

## 暂缓

持续监控告警、常驻 Agent、绑定码、插件、FTP/Python、模板变量、历史版本、多人权限、自动 DNS、多系统支持。

具体实施发现问题，先更新受影响规则和测试再改实现；不因写了设计文档就假设稳定性已被证明。
