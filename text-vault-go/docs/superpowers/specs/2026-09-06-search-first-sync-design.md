# Text Vault 搜索优先界面与自动同步设计

## 目标

把现有 Text Vault 收束成一个可以长期日用、容易阅读和继续扩展的个人记录工具。当前版本只做好纯文本条目，但保留“数据 → 查询 → 视图”的边界，以后可以增加表格、附件和其他视图，而不推翻文本数据与同步层。

交互的核心只有搜索、结果和内容。应用内部不再模拟浏览器标签页；每个浏览器标签页就是一个独立的查询现场。

## 设计原则

- VanJS 只负责少量响应式状态和真实 DOM；业务逻辑使用普通 JavaScript。
- 优先使用浏览器原生 API，不引入构建步骤和大型框架。
- 文件按职责拆分，数据流显式，关键设计边界写块级注释。
- SQLite 保存加密后的对象版本；服务器不接触保险库明文和主密码。
- 自动保存和同步不增加用户选择：界面中没有“保存当前条目”。
- 当前版本不实现 CRDT、WebSocket、多用户协作、附件或表格。

## 界面

### 桌面

页面由四个区域组成：

1. 顶部全宽、约 6px 的纯色状态细条。
2. 左侧结果列表。
3. 右侧纯文本内容编辑器。
4. 底栏：左侧搜索/命令输入框，右侧当前条目的时间、ID 等信息。

左右列使用固定、简单的 CSS 网格，不再提供拖动分栏，也不保存布局状态。深色主题只使用少量颜色、边线和间距，不使用阴影、渐变、动画或装饰性组件。

### 手机

页面由三个区域组成：

1. 同一条顶部状态细条。
2. 中间一次显示结果列表或条目内容。
3. 底栏随页面变化：列表页显示搜索框；内容页显示返回操作以及条目时间、ID 等信息。

从内容返回列表时保留当前查询和列表位置。浏览器前进、后退与页面内部的列表/内容导航保持一致，不出现右侧空白或内容意外跟随的问题。

### 状态细条

状态只用颜色表达，不显示文字：

- 正常：比页面背景稍浅的中性色。
- 本地存在未上传修改或正在保存：暗红色。
- 保存或同步失败、离线：更醒目的红色。

为了不依赖颜色传递可访问性信息，细条同时设置简短的 `title` 和 `aria-label`，但视觉上不出现文本。查询、选择条目和移动端页面切换不会制造未保存状态。

## 查询、导航与浏览器标签页

查询写入 URL fragment，例如 `#q=example.com`。fragment 不发送给 Go 或 Caddy，但可能被浏览器历史、会话恢复、扩展和页面脚本读取，因此密码和命令永远不写入 URL。

搜索输入每次变化后立即查询内存中的已解密条目。编辑器内容先进入内存仓库，所以尚未上传的修改也能立即被搜索到。

键盘操作：

- `ArrowDown` / `ArrowUp` 在可见结果间移动选择。
- `Enter` 打开选中的条目；没有结果时创建新条目。
- `Escape` 从内容回到列表，或清除当前临时选择。
- “在新标签页打开查询”使用普通浏览器新标签页和带 fragment 的 URL，不建立应用内部标签模型。

## 命令输入

当输入以 `/` 开头时，输入框进入命令模式，不再执行普通全文查询，也不更新 URL。结果列表显示匹配的虚拟命令条目；上下键选择，回车执行。命令本身不会成为数据条目。

首版只有两个命令：

### `/s`

立即触发一次全局保存。全局保存的含义是提交仓库内全部 dirty 对象；实际网络请求仍然只包含有变化的对象。没有“保存当前条目”的第二套操作。

### `/changepwd`

回车后在同一个底部输入区域进入临时命令会话：

1. 使用密码输入框输入新密码。
2. 再输入一次。
3. 显示 `确认修改？y/N`，只有输入 `y` 后执行。

新密码不进入 URL、搜索索引、持久化前端状态或日志。两次输入不一致时留在命令会话并提示重新输入。改密只用新密码重新包裹既有数据密钥，并更新服务器认证凭据；条目密文使用的数据密钥不变，因此无需重写所有条目。新的密钥包裹与认证散列在一个 SQLite 事务中提交，失败时旧密码仍然有效。`Escape` 或 `n` 取消。

命令解析器使用一个普通对象注册命令名、说明和执行函数，便于以后添加命令，但不为尚未实现的 `/d` 建立删除逻辑。

## ID

采用 `apps/vanjs/garden/src/memoId.js` 的 9 字符 ID 规则：压缩时间前缀加同一分钟内的两位 base36 序号。保留精确的 `createdAt` 和 `updatedAt` 字段。

客户端生成新 ID 前先基于当前内存数据计算下一个序号。SQLite 主键仍是最终唯一性保护。若多个标签页或设备极少数情况下生成相同 ID，服务器拒绝冲突；客户端先拉取远端变化，再为尚未持久化的新条目生成下一序号并重试。后端 ID 校验允许 9 字符 ID。

## 自动保存

编辑发生后：

1. 文本立即写入内存仓库并标记对应对象 dirty。
2. 搜索立即看到新内容。
3. 停止输入约 1 秒后自动保存 dirty 对象。
4. `/s`、标签页失去焦点以及页面隐藏时也尝试立即保存。

页面关闭前如果仍有 dirty 对象，使用原生 `beforeunload` 提醒；已经保存时不拦截。自动保存和手动 `/s` 共用同一个保存控制器，避免两套行为。

布局、查询、选择以及浏览器导航不是服务器数据，不参与保存状态。

## 增量读取与冲突

服务器继续维护全局 `generation` 和每个对象的 `revision`，新增增量读取接口：

```text
GET /api/changes?after=<generation>
```

响应只包含该 generation 之后变化的加密对象版本以及最新 generation。客户端：

- 每 2 秒增量读取一次。
- 标签页重新获得焦点时立即读取。
- 打开条目前读取一次。
- 自动保存前读取一次，再提交本地变化。

远端变化指向不同的本地 dirty 条目时可以直接合并。远端和本地同时修改同一个条目时禁止静默覆盖：保留本地编辑，并把远端版本保存为一个明确的冲突副本；顶部细条进入失败色，条目列表中可搜索到两个版本。这个模型是个人多标签页同步，不宣称支持多人实时共同编辑同一条目。

## 同浏览器自动解锁

任何新打开、刷新、复制或手工输入地址得到的同源标签页，先渲染深色应用外壳，然后通过 `BroadcastChannel` 请求已解锁标签页提供会话材料。已解锁标签页通过结构化克隆传递内存中的 `CryptoKey` 和必要的 CSRF 会话信息。

新标签短暂等待约 500ms：收到密钥就直接载入界面；没有可响应的标签页才显示主密码解锁层。密钥不写入 URL、localStorage 或 sessionStorage。不同浏览器、不同配置目录、隐私窗口或被 iOS 挂起的标签页不能保证自动解锁，届时正常回退到输入密码。

## 后端与数据边界

Go 后端承担：认证会话、CSRF、SQLite 事务、加密对象版本保存、generation 分配、增量读取和静态文件服务。浏览器承担：主密码派生、加解密、内存搜索、编辑状态和视图。

改密沿用专门的原子后端操作，确保新的数据密钥包裹与认证散列一次成功或一次失败，并在事务成功后刷新进程内认证状态。数据库结构可以直接调整，不为当前未发布数据编写长期兼容迁移；实施时会明确给出数据库重建或手工调整步骤。

## 代码边界

- `app.js`：组合界面和顶层交互，不承载加密或存储细节。
- `repository.js`：内存对象、查询、dirty 管理、远端合并和冲突副本。
- `save.js`：自动保存调度、串行提交、状态机。
- `sync.js`：generation 游标、轮询和增量读取。
- `commands.js`：命令识别、虚拟结果和命令会话。
- `tab-session.js`：BroadcastChannel 解锁材料交接。
- `model.js`：memoId、条目创建和纯数据转换。
- `api.js` / `crypto.js`：分别隔离 HTTP 和 Web Crypto。

模块名可在实施时按现有测试结构微调，但职责不合并成巨型文件。

## 错误处理

- 网络失败不丢弃 dirty 数据，恢复网络后继续重试。
- 保存请求串行化；编辑发生在保存途中时，下一轮继续保存新 revision。
- 解密失败只隔离问题对象，不清空本地仓库。
- 改密失败保持旧密码和旧密文仍然有效。
- 服务端 revision 或 ID 冲突均返回明确错误码，由仓库层处理，不在 UI 层猜测错误字符串。

## 验证

### JavaScript 单元测试

- memoId 同分钟递增、跨分钟重置、解析和冲突重试。
- 普通查询与命令模式互斥，命令不进入 URL。
- 上下键选择、回车打开、新建逻辑。
- dirty 捕获、保存途中继续编辑、增量合并和同对象冲突副本。
- 自动保存计时与 `/s` 共用保存路径。
- 改密会话的重复输入、取消和确认。

### Go 测试

- 9 字符 ID 校验。
- changes 接口严格按 generation 返回版本。
- revision/ID 冲突响应。
- 改密事务成功和中途失败回滚。

### 浏览器端到端测试

- 桌面左右布局、手机列表/内容切换和返回。
- 搜索键盘导航与 URL fragment 恢复。
- 两个标签页之间自动解锁、自动保存、增量出现新增和修改。
- 同一条目并发修改不会被静默覆盖。
- 顶部细条在正常、dirty 和错误状态显示正确颜色。

## 完成标准

用户在一个标签页解锁后，可以无感打开更多同源标签页，以 URL 保存各自查询现场；编辑内容约一秒后自动加密保存，其他标签页和设备约两秒内看到增量变化。桌面保持两列，手机自然切换列表与内容。界面不再出现内部标签、Pin、布局保存或单条保存选择，并能用键盘完成搜索、选择、打开、保存和改密。
