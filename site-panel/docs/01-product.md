# 01 产品与操作规则

## 1. 数据归属

- 主控保存页面、Vue 构建产物、APK、域名/Nginx 配置，以及取回的证书和私钥。
- 面板文件管理操作主控目录，不直接编辑节点运行目录。
- 保存不等于上线。文件点击同步，配置点击应用；首次部署提供顺序执行的组合操作。
- 主控保存最新希望运行的内容，节点保留最后成功应用的内容。分别显示未应用、应用中、成功、失败/未知，不把保存成功当上线成功。
- 节点不作为另一处编辑入口。人工修改节点文件可能被下次同步覆盖，不做双向合并。
- 不做用户可见版本历史，用户可以手动重命名文件保留旧内容。任务临时目录和单次失败恢复资料不属于历史版本功能。

## 2. 登录

单账号、单有效会话，新登录失效旧会话。首次初始化密码，无通用默认密码，密码存哈希。保留限速、会话验证、写操作 CSRF 防护；单会话不能代替节点任务互斥。

本地开发默认仅监听 127.0.0.1，不开放管理接口到公网。以后共享面板需配置 HTTPS 和相应 Cookie 安全属性。

## 3. 节点列表

字段：名称、IP/地址、SSH 端口、用户、备注、连接状态、执行器版本、安装结果、最近采集时间。

操作：添加并自动安装、编辑连接资料、刷新状态、重试安装、进入站点、移除节点。

- 保存 SSH 密码但不回显；留空编辑表示不修改密码。
- 首次连接确认 SSH 指纹，后续变化拒绝静默连接。IP 相同不意味着还是原服务器。
- 安装先检查支持的系统和已有业务，遇到宝塔或非本系统 Nginx 等冲突停止，不直接覆盖。
- 不需要节点回连主控或输入绑定码；本地只需能访问节点 SSH。
- 状态是主控通过 SSH 采集的快照，不是持续心跳。连接失败显示“不可达/状态未知”，并保留最后成功采集时间。

### 删除与重新添加

移除节点前提示可能仍有已启动任务。移除仅停止主控管理、删除本地主机连接凭据，站点原件保留并解除关联，不停止远端 Nginx、不删除文件或执行器。

重新添加已安装节点：检查主机指纹和执行器标记，复用或明确更新执行器，不清空站点、不自动同步。需要用户选择原站点重新关联。不同主控的安装标记要求确认接管。

移除记录不会撤销服务器上的 SSH 密码，也不能取消已经启动的任务。若需禁止旧主控继续登录，要在服务器更换密码/撤销密钥。第一版不提供危险的一键卸载清空。

## 4. 站点列表

字段：稳定 ID、名称、备注/可选客户标签、所属节点、域名、端口、节点目录、文件同步状态、配置状态、证书状态。

操作：添加、Nginx 编辑、文件管理、同步、应用配置、SSL（后续）、暂停、恢复到其他节点、删除。

主控以站点 ID 组织原件，不因改域名/名称而重命名。节点默认目录 /srv/site-panel/sites/<site-id>/current；自定义目录只能在受管根目录内，不允许系统目录、站点父子目录重叠或链接逃逸。

纯代理站不需要静态文件。共享 80/443 的不同域名是正常用法，不简单拒绝重复端口；检查重复域名、重复默认站点与其他服务占用。

## 5. Nginx 配置与域名

第一版以完整站点配置文本为唯一权威，域名、端口和 root 在同一编辑页查看/修改；列表从配置中提取可识别的内容。不维护另一套独立可写域名表单。无法识别的高级写法标为自定义，不能擅自重写。

受管配置仅为 HTTP 站点 server 块，不支持修改全局 nginx.conf、加载模块、stream、QUIC 或随意 include。证书和站点路径需属于允许范围。任意原文配置仍是高权限功能，不能当安全沙箱；实现时限定支持语法，对不能安全处理的配置明确拒绝，不承诺兼容所有 Nginx 写法。

应用时检查整个候选配置树，通过才 reload。nginx -t 通过不代表代理后端可访问或业务路由正确，失败提示需区分。

Vue history 路由、/api/ 路径保留与否、WebSocket 等由实际配置决定，不作为模板主线。

## 6. 文件管理与同步

第一步先做上传、列表和文本编辑；闭环成功后补新建、下载、重命名、删除、ZIP 解压。

- 大文件流式传输，不把 APK 整体放进内存/base64 JSON。
- 路径严格限制在所属站点内；禁止用户文件符号链接和危险文件类型。
- 文本编辑设大小/编码限制，ZIP 设展开大小/数量限制并阻止路径穿越。
- 同步时冻结主控输入，节点完整准备后切换，不边传边覆盖线上。
- 同步包含删除时，展示删除预览后确认；主控文件已删不意味着节点立刻删除。
- 原件修改后如果尚未同步，界面明确提示；同步失败可查询具体阶段并重试。
- 旧 hash 静态资源和浏览器缓存需要用户合理管理；不承诺旧页面永远可加载已删除资源。

删除站点默认先禁用远端配置，再确认清理。远端不可达不能声称已清理，用户可明确选择仅移除主控记录并接受遗留内容风险。不能默默删掉唯一原件。

## 7. SSL（静态站闭环后）

先支持上传证书与 ACME HTTP-01，不同时接十几个 DNS 平台。节点独立签发/续期，主控主动查询结果并通过 SSH/SFTP 取回证书和私钥，无节点回传网络请求。

- 相同域名换 IP 可复用有效证书；换域名需证书覆盖新域名。
- 域名、A/AAAA、80 端口、CAA、CA 限流等可能导致申请失败；不能保证立即签发。
- 普通文件同步不覆盖证书，续期后不能被主控旧副本覆盖。
- 主控离线不影响续期；离线期间主控证书副本可能滞后，界面显示最后取回时间。
- 取回验证证书/私钥匹配、域名、有效期与指纹，不能用旧采集结果覆盖新副本。
- 更新成功后检查并加载 Nginx；失败保留当前可用证书。
- 私钥不通过普通站点文件管理暴露。

## 8. 换机恢复与边界

目标节点安装 → 从主控准备当前文件/配置/有效证书 → 校验和部署 → 用指定 Host/SNI 验证新 IP → 用户切 DNS/App 地址 → 确认新节点关联。

原节点不自动清空；失败不提前解除原绑定。第一版站点有一个当前目标节点和一个临时迁移目标，不扩展多活调度。

恢复不依赖旧节点，但依赖主控保存的内容。如果主控未同步、证书未取回或原件已误删，不能承诺恢复到节点故障前最后状态。主控自身需要独立备份。

## 9. 暂缓

常驻 Agent、完整监控告警、插件、FTP、Python 托管、模板变量、历史版本、多用户权限、自动 DNS、多系统兼容。未来功能不能悄悄改变“主控是唯一文件原件”的规则。
