# desk

个人有限白板。从板子进入；条目只在一个集合里；能力靠搜索。

通用技术偏好见 `../WEB-DEVELOPMENT-PREFERENCES.md`。  
早先同向笔记见 `../thinking-desk/IDEA.md`（暂停稿，实施以本目录为准）。

## 已定

- 数据 → 查询 → 视图；原理要透明，少依赖，贴 Web 标准
- VanJS + goober（或纯 CSS），浏览器 ESM，无构建优先
- IndexedDB 手写（或可读完的薄封装）；图片 Blob 挂在条目上
- 板上：字条目、带图条目、无关联的装饰线；固定 16:9，位置要记住
- 搜索：空格 = AND；链接也是搜索；可从搜进板
- 手动 JSON 导入导出；云备份以后再说
- 纯本地初版；不提前上 Go

## 初版不做
