# desk

个人有限白板。从板子进入；条目只在一个集合里；能力靠搜索。

通用技术偏好见 `../WEB-DEVELOPMENT-PREFERENCES.md`。  
早先同向笔记见 `../thinking-desk/IDEA.md`（暂停稿，实施以本目录为准）。

## 已定

- 数据 → 查询 → 视图；原理要透明，少依赖，贴 Web 标准
- VanJS + goober（或纯 CSS），浏览器 ESM，无构建优先
- IndexedDB 手写（或可读完的薄封装）；图片 Blob 挂在条目上
- 板上：字条目、带图条目、无关联的装饰线；固定 16:9，位置要记住
- 搜索：空格 = AND；链接也是搜索；可从搜进板
- 手动 JSON 导入导出；云备份以后再说
- 纯本地初版；不提前上 Go

## 风格：这是自己的小世界（函数式偏向）

对齐 `../ARCHITECTURE-WORLDVIEW.md` 与偏好里的 VanJS 纪律，不为炫技：

- **室内尽量纯**：查询、缩放换算、空格 AND、从旧世界算出新世界 → 普通函数，输入定输出
- **状态当不可变快照**：事件里用「旧状态 + 动作 → 新状态」替换整份引用（Van 的 `.val =`），不随手改对象字段
- **视图只派生**：从状态算出 DOM；不在视图里偷改业务真相
- **出门集中**：IndexedDB、选文件、改 DOM 是副作用；门薄、次数少、位置显眼
- **一份真相一个主笔**：世界数据只有一处在写；板面 DOM 是影

不搞 Haskell 仪式；要的是：**逻辑好测、好读、改一处不炸全家**——顺便练 JS 函数与数据流。
